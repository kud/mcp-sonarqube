---
title: ⚙️ Configuration
description: Host, token and the config file.
---

Configuration is resolved by the `@kud/sonarqube` core, in layers: config file, then environment.

| Setting | Environment       | File key |
| ------- | ----------------- | -------- |
| host    | `SONARQUBE_HOST`  | `host`   |
| token   | `SONARQUBE_TOKEN` | `token`  |

The file is `$XDG_CONFIG_HOME/sonarqube/config.json` (default `~/.config/sonarqube/config.json`). There is no default host: the server exits at start-up without one. A 401 names the token variable to set.

Older variable names and the previous config directory are still read as fallbacks, so existing set-ups keep working.

```json
{
  "mcpServers": {
    "sonarqube": {
      "command": "npx",
      "args": ["-y", "@kud/mcp-sonarqube@latest"],
      "env": {
        "SONARQUBE_HOST": "https://sonarqube.example.com",
        "SONARQUBE_TOKEN": "<your-token>"
      }
    }
  }
}
```
